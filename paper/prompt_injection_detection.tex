\begin{abstract}
Prompt injection attacks against large language models demand robust real-time defenses. This paper investigates three questions: (1)~whether embedding representations contain discriminative information for prompt injection detection, (2)~why nearest-centroid classification fails on these embeddings, and (3)~whether lightweight statistical features offer a viable alternative. Through controlled experiments across embedding models on 144,569 test samples, we find that the embedding space contains discriminative information (linear probes achieve AUC 0.844--0.855) that nearest-centroid scoring cannot access (AUC 0.547). The critical factor is the number of centroids: 4 category centroids overlap ($C = 0.986$) while 2 class centroids achieve AUC 0.763--0.784. We then evaluate a lightweight hybrid guardrail combining 117 handcrafted features, TF-IDF similarity, and a stacking ensemble. The hybrid model achieves 83.0\% in-distribution accuracy with a measured single-threaded CPU inference latency of 0.149\,ms per prompt. An ablation study reveals that TF-IDF alone (85.0\% accuracy) outperforms the full hybrid, indicating that, under the evaluated setting, the 117 handcrafted features do not provide complementary predictive value beyond TF-IDF. Cross-dataset evaluation on four external benchmarks reveals a severe generalization gap: performance drops from 83.0\% to 51.5\% (a 31.5 percentage-point decline). We present a detailed analysis of the model's strengths, weaknesses, and failure modes, providing experimentally grounded guidance for designing prompt injection detection systems.
\end{abstract}

\noindent\textbf{Keywords:} prompt injection, LLM security, nearest-centroid, linear probe, hybrid guardrail, lightweight classifier, cross-dataset generalization

\section{Introduction}\label{sec:intro}
%===========================================================================

The deployment of large language models (LLMs) in production systems has created an urgent security challenge: prompt injection attacks~\citep{schulhoff2023hackaprompt, greshake2023not}. These adversarial inputs attempt to override system instructions, extract confidential prompts, or bypass safety alignments~\citep{liu2023prompt}. Unlike traditional software vulnerabilities, prompt injections exploit the fundamental architecture of autoregressive models, where user input and system instructions share the same processing context.

An intuitive defense is to use embedding models to compare inputs against known attack corpora via semantic similarity. This paper investigates whether this approach can work, why it fails under certain configurations, and whether lightweight statistical features offer a viable alternative. We address three research questions:

\begin{enumerate}[leftmargin=*]
    \item \textbf{RQ1: Does the embedding representation contain discriminative information for prompt injection detection?}
    
    Under the evaluated dataset, yes. Linear probes trained on the same embeddings used for centroid scoring achieve AUC 0.844--0.884, indicating that discriminative structure exists in the embedding space even when centroid-based methods fail to exploit it.

    \item \textbf{RQ2: Why does the original centroid-based classifier fail?}
    
    The results indicate that the failure is primarily associated with the classification method rather than an absence of discriminative information in the evaluated embeddings. Four category centroids overlap in cosine similarity space ($C = 0.986$), preventing effective nearest-centroid classification. Reducing to two class centroids (malicious vs.\ benign) improves AUC from 0.547 to 0.763--0.784, and learned linear boundaries perform better still (AUC 0.844--0.884).

    \item \textbf{RQ3: Can lightweight statistical features provide a computationally efficient alternative?}
    
    A hybrid guardrail combining 117 handcrafted features, TF-IDF similarity, and a stacking ensemble achieves 83.0\% in-distribution accuracy with a measured single-threaded CPU inference latency of 0.149\,ms per prompt. However, an ablation study reveals that TF-IDF alone achieves 85.0\% accuracy, exceeding the full hybrid, suggesting that handcrafted security features do not complement distributional representations under the evaluated setting. Cross-dataset evaluation on four external benchmarks reveals a severe generalization gap: performance drops to 51.5\% (a 31.5 percentage-point decline), suggesting that strong in-distribution results do not necessarily indicate robustness.
\end{enumerate}

Our contribution is threefold:
\begin{enumerate}[leftmargin=*]
    \item We systematically investigate why nearest-centroid scoring fails on the evaluated embedding representations, showing that the 4-centroid max-similarity configuration performs poorly despite the presence of discriminative information accessible to learned classifiers.
    \item We demonstrate that linear probes and 2-centroid classifiers recover discriminative structure from the same embeddings, indicating the embedding space contains security-relevant information.
    \item We present a lightweight hybrid guardrail with detailed strength/weakness analysis, including an ablation study showing TF-IDF alone outperforms the full hybrid, and a severe cross-dataset generalization gap (31.5 percentage-point decline).
\end{enumerate}

\section{Related Work}\label{sec:related}
%===========================================================================

Prompt injection attacks exploit the shared context of user input and system instructions in autoregressive language models~\citep{schulhoff2023hackaprompt, greshake2023not, liu2023prompt}. Attack types include direct injection, indirect injection, system prompt extraction, jailbreak~\citep{perez2023jailbreak, wei2023jailbroken}, and refusal bypass~\citep{li2024chatgpt}. Defense approaches include instruction hierarchy~\citep{wallace2024instruction}, perplexity-based detection~\citep{alon2023detecting}, and retrieval-augmented systems using embedding similarity~\citep{reimers2019sentence, xiao2023bge}. Recent work has explored LLM-based classifiers and feature-engineered models for injection detection, though most evaluations remain in-distribution~\citep{liu2023prompt}. In representation learning, \citet{khosla2020supervised} demonstrated supervised contrastive learning, and \citet{jing2022dimensional} identified dimensional collapse. Our work examines a related phenomenon in the security domain: substantial overlap between class centroids in embedding space ($C = 0.986$), which is associated with poor nearest-centroid classification performance, even though trained linear probes can extract discriminative structure.

\section{The Embedding Failure}\label{sec:phase6}
%===========================================================================

The embedding pipeline was designed as a routine validation step: test the embedding approach on the corrected 722K dataset with proper train-test separation. Instead, it revealed significant performance limitations.

The embedding scoring pipeline used bge-large-en-v1.5~\citep{xiao2023bge} to convert prompts into 1024-dimensional embeddings, then computed 7 weighted signals: $s_{\text{composite}} = 0.30 \cdot s_{\text{sparse\_idf}} + 0.25 \cdot s_{\text{centroid}} + 0.10 \cdot s_{\text{perplexity}} + 0.10 \cdot s_{\text{entropy}} + 0.10 \cdot s_{\text{token\_freq}} + 0.10 \cdot s_{\text{ngram}} + 0.05 \cdot s_{\text{length}}$. The centroid signal computes maximum cosine similarity~\citep{duda2001pattern} across 4 category centroids: $s_{\text{centroid}} = \max_{c \in \mathcal{C}} \cos(\mathbf{x}, \mu_c)$. Classification is threshold-based: $y = \mathbb{1}[s_{\text{composite}} \geq \tau]$.

We conducted four experiments to answer this. All investigation experiments use a 10,000-sample stratified subset (8,000 train / 2,000 test) to enable rapid iteration across four embedding models; the hybrid guardrail experiments use the full dataset.

\subsection{The Critical Discovery: Why 4 Centroids Fail While 2 Centroids Work}\label{sec:4v2}

The embedding method assigns each test prompt to the nearest category centroid using cosine similarity:
\begin{equation}
\hat{y} = \arg\max_{c \in \mathcal{C}} \cos(\mathbf{x}, \mu_c) = \arg\max_{c \in \mathcal{C}} \frac{\mathbf{x} \cdot \mu_c}{\|\mathbf{x}\| \|\mu_c\|}
\label{eq:centroid_classify}
\end{equation}
where $\mathcal{C} = \{\text{benign}, \text{jailbreak}, \text{injection}, \text{extraction}\}$ and $\mu_c = \frac{1}{|S_c|}\sum_{i \in S_c} \mathbf{x}_i$ is the mean embedding (centroid) of category $c$ computed from the training set.

With 4 centroids, the classifier produces a 4-class prediction which is collapsed to binary: $\hat{y}_{\text{binary}} = \mathbb{1}[\hat{y} \neq \text{benign}]$. The inter-centroid cosine similarity is:
\begin{equation}
C = \frac{1}{|\mathcal{C}|(|\mathcal{C}|-1)} \sum_{i \neq j} \cos(\mu_i, \mu_j)
\label{eq:centroid_C}
\end{equation}

In our experiment, $C = 0.986$ across all 4 centroids on the full 722K dataset ($C = 0.909$ on the 10K subset). This means the three malicious centroids are nearly indistinguishable from each other and from the benign centroid in cosine space. When centroids overlap this severely, the argmax decision boundaries become essentially random among the 4 categories, yielding 40.2\% accuracy on 722K and 68.3\% on 10K---both insufficient for practical deployment.

When the three malicious categories are merged into a single class, the classification becomes:
\begin{equation}
\hat{y}_{\text{binary}} = \mathbb{1}\left[\cos(\mathbf{x}, \mu_{\text{malicious}}) > \cos(\mathbf{x}, \mu_{\text{benign}})\right]
\label{eq:centroid_binary}
\end{equation}

The merged malicious centroid $\mu_{\text{malicious}} = \frac{1}{|S_{\text{mal}}|}\sum_{i \in S_{\text{mal}}} \mathbf{x}_i$ aggregates the shared representation of all three attack types while reducing category-specific variation. This improves accuracy to 71.8\% (AUC 0.772), a 31.6 pp gain, because the binary decision boundary only needs to separate two clusters rather than resolve four overlapping ones. The centroid similarity $C$ remains 0.986 (measured between the two remaining centroids), confirming that even with 2 centroids, the benign and malicious classes overlap substantially in cosine space---but the binary classification is robust enough to extract a usable boundary.

\subsection{Interpreting the Centroid Paradox}\label{sec:paradox}

The central finding of our investigation is a paradox: nearest-centroid scoring fails (AUC 0.547) while linear probes succeed (AUC 0.884) on the same embeddings. This paradox reveals a fundamental limitation of centroid-based classification in high-dimensional spaces.

A nearest-centroid classifier assigns $\hat{y} = \arg\max_c \cos(\mathbf{x}, \mu_c)$. This is equivalent to a nearest-neighbor classifier with $k=1$ where the prototype for each class is its mean. The decision boundary between two classes $i$ and $j$ is the hyperplane:
\begin{equation}
\mathbf{w} = \mu_i - \mu_j, \quad \text{classify as } i \text{ if } \mathbf{x} \cdot \mathbf{w} > \frac{\|\mu_i\|^2 - \|\mu_j\|^2}{2}
\label{eq:centroid_boundary}
\end{equation}

This boundary depends only on the class means. When $C = \mu_i \cdot \mu_j \approx 1$ (as in our experiment where $C = 0.986$), the means are nearly collinear, and the boundary becomes extremely sensitive to small perturbations in the data. The classifier cannot exploit structure beyond the first moment of each class distribution.

A logistic regression linear probe learns a weight vector $\mathbf{w}^*$ that maximizes the likelihood of the training data:
\begin{equation}
\mathbf{w}^* = \arg\max_{\mathbf{w}} \sum_{i=1}^{n} \left[ y_i \log \sigma(\mathbf{w}^\top \mathbf{x}_i) + (1-y_i) \log(1 - \sigma(\mathbf{w}^\top \mathbf{x}_i)) \right]
\label{eq:logreg}
\end{equation}
where $\sigma(z) = 1/(1+e^{-z})$ is the sigmoid function. Unlike the centroid classifier, logistic regression optimizes $\mathbf{w}$ over all training examples simultaneously, finding a direction in the 1024-dimensional space that best separates the classes. It is not constrained to use the class means as prototypes.

In high-dimensional spaces ($d = 1024$), two classes can have nearly identical means ($C = 0.986$) while remaining linearly separable along other dimensions. The centroid classifier can only see the projection onto the $\mu_i - \mu_j$ direction, which is uninformative when $C \approx 1$. The linear probe can find a separating hyperplane in the full 1024-dimensional space, exploiting structure that is invisible to the centroid-based approach. This explains why linear probes achieve AUC 0.844--0.884 while nearest-centroid achieves only 0.547 on the same embeddings.

\subsection{Why StandardScaler Helps}\label{sec:scaler}

The Euclidean distance with StandardScaler outperforms cosine similarity (AUC 0.784 vs.\ 0.772) despite using the same 2-centroid classification. We analyze why through the lens of distance weighting.

StandardScaler transforms each dimension $j$ to zero mean and unit variance:
\begin{equation}
x_j^{\text{scaled}} = \frac{x_j - \mu_j}{\sigma_j}
\label{eq:scaler}
\end{equation}
where $\mu_j$ and $\sigma_j$ are the mean and standard deviation of dimension $j$ across the training set. The squared Euclidean distance between two scaled points $\mathbf{x}$ and $\mathbf{y}$ is:
\begin{equation}
d^2(\mathbf{x}^{\text{scaled}}, \mathbf{y}^{\text{scaled}}) = \sum_{j=1}^{d} \left(\frac{x_j - y_j}{\sigma_j}\right)^2 = \sum_{j=1}^{d} \frac{1}{\sigma_j^2} (x_j - y_j)^2
\label{eq:weighted_euc}
\end{equation}

This is equivalent to a weighted Euclidean distance where each dimension $j$ receives weight $w_j = 1/\sigma_j^2$. Dimensions with low variance ($\sigma_j$ small) receive high weight, while high-variance dimensions are downweighted. In the context of bge-large-en-v1.5 embeddings, which are normalized to unit length, most dimensions have very similar variance across the dataset. However, dimensions that are discriminative between classes tend to have lower within-class variance---they are ``stable'' for each class but differ between classes. StandardScaler amplifies these dimensions by assigning them higher weight.

Cosine similarity, by contrast, normalizes only the vector magnitude:
\begin{equation}
\cos(\mathbf{x}, \mu_c) = \frac{\mathbf{x} \cdot \mu_c}{\|\mathbf{x}\| \|\mu_c\|}
\label{eq:cosine}
\end{equation}

This treats all dimensions equally (uniform weight $w_j = 1$), regardless of their discriminative power. StandardScaler's inverse-variance weighting provides a form of automatic feature selection, upweighting dimensions that vary little within classes but differ between them. This explains the observed AUC improvement from 0.772 (cosine) to 0.784 (Euclidean + StandardScaler) with the same 2-centroid classification method.

\section{Hybrid Guardrail V3: Architecture}\label{sec:hybrid}
%===========================================================================

The hybrid guardrail combines three signal layers with a stacking ensemble classifier, designed to capture security-relevant patterns that general-purpose embeddings miss.

\subsection{Feature Engineering (117 Features)}

The model extracts 117 handcrafted features from each prompt, organized into 14 categories: basic statistics (6), character ratios (6), entropy (4), attack keywords (3), encoding detection (6), structural patterns (6), lexical repetition (3), structural flags (10), advanced structural (12), linguistic (12), readability (10), n-gram diversity (2), injection-specific (8), and punctuation (10).

\subsection{Pattern Matching (Aho-Corasick)}

An Aho-Corasick automaton~\citep{aho1975multi} matches 47 regex patterns in a single pass: $\text{score}_{\text{regex}}(t) = \max_{p \in \mathcal{P}} s_p$ if $p$ matches $t$, else 0. Patterns include instruction overrides (0.95), role hijacking (0.90), system extraction (0.95), and delimiter injection (0.90).

\subsection{TF-IDF Similarity (Quantized)}

TF-IDF similarity~\citep{manning1999foundations} was quantized to int8 for memory-efficient inference.

\subsection{Stacking Ensemble}

The stacking classifier combines XGBoost (500 trees, depth 6, lr 0.05), LightGBM (500 trees, depth 6, lr 0.05), and Random Forest (300 trees, depth 12) as base learners, with a logistic regression meta-learner, followed by isotonic calibration.

\subsection{Ensemble Decision}

The final ensemble combines the three signal layers:
\begin{equation}
\text{ensemble} = w_0 \cdot \text{score}_{\text{regex}} + w_1 \cdot \text{score}_{\text{sim}} + w_2 \cdot P_{\text{cal}}(x)
\label{eq:ensemble}
\end{equation}
where $P_{\text{cal}}(x)$ is the calibrated stacking probability. The weights $[w_0, w_1, w_2]$ are initialized to $[0.10, 0.10, 0.80]$ and adapted online during inference via softmax:
\begin{equation}
w_i^{(t)} = \frac{\exp(a_i^{(t)})}{\sum_j \exp(a_j^{(t)})}, \quad a_i^{(t)} = \alpha \cdot a_{\text{comp},i}^{(t)} + (1-\alpha) \cdot a_i^{(t-1)}
\label{eq:adaptive_weights}
\end{equation}
where $\alpha = 0.05$ and $a_{\text{comp},i} = [1 - \text{fp\_rate}_i, 1 - \text{fn\_rate}_i, \text{accuracy}_i]$ for each component. The stacking probability dominates because it achieves the highest individual accuracy; the adaptive mechanism reinforces this assignment. The regex and similarity signals remain at low weights because their individual discriminative power is lower.

\subsection{Training Setup}

\begin{itemize}[leftmargin=*]
    \item \textbf{Dataset:} 722,842 samples, 80/10/10 stratified split (578,273 train / 72,284 val / 72,285 test)
    \item \textbf{TF-IDF:} Word-level (5,000 features, bigrams, sublinear TF)
    \item \textbf{Stacking:} 3-fold CV, passthrough=True
    \item \textbf{Calibration:} Isotonic regression on validation set
    \item \textbf{Hardware:} Kaggle P100-PCIE-16GB, $\sim$5 hours training
\end{itemize}

TF-IDF-only achieves 85.0\% accuracy and F1$=$0.848, exceeding the full model (83.0\%, F1$=$0.827) by 2.0 pp. Training and validation AUC were also higher for TF-IDF-only than the full configuration, consistent with the test-set ablation. %===========================================================================
\section{Discussion}\label{sec:discussion}
%===========================================================================

\subsection{Main Findings and Practical Strengths}

The central finding is that nearest-centroid scoring on general-purpose embeddings fails (AUC 0.547), yet the same embedding space contains discriminative information accessible to trained classifiers (AUC 0.844--0.884). This motivated a lightweight hybrid guardrail achieving 83.0\% in-distribution accuracy at 0.149\,ms/prompt (6,727 prompts/s) on CPU, with well-calibrated probabilities (ECE $= 0.0161$) and 100\% Base64 detection.

\subsection{Limitations and Failure Modes}

\textbf{Cross-dataset generalization failure.} In-distribution accuracy drops from 83.0\% to 51.5\% ($-$31.5 pp) on four external benchmarks. Jailbreak Complete DS achieves 42.2\% (below 0.50), and JailbreakHub achieves F1 $= 0.220$, indicating dataset-specific pattern memorization.

\textbf{Misspelling vulnerability.} Detection drops to 63.5\% against character substitution, confirming reliance on character-exact TF-IDF matching.

\textbf{High false-positive rate.} At 25.0\%, the FPR would generate unacceptable noise in user-facing settings.

\textbf{Feature limitations.} Under the evaluated setting, the 117 handcrafted features did not complement TF-IDF (ablation: TF-IDF-only 85.0\% vs.\ full 83.0\%). The recommended deployment is TF-IDF-only (ECE 0.0069 vs.\ 0.0161).

\textbf{Limited robustness evaluation.} The 8 tested transformations ($n=200$) did not include adaptive adversarial attacks.

\textbf{Embedding compute constraints.} The linear probe, 2-centroid cosine similarity, and Euclidean + StandardScaler experiments (Table~\ref{tab:method_comparison}, Rows 2--5) were evaluated on 10,000 stratified samples due to the computational cost of generating and storing 1024-dimensional embeddings for the full 722K dataset. This highlights a practical limitation of embedding-based approaches: they require substantial compute for both training and inference compared to lightweight feature-based methods.

\subsection{Practical Implications}

Production deployment requires: (1)~multi-source training data for generalization; (2)~character-level normalization for misspelling robustness; (3)~cost-sensitive training to reduce FPR; and (4)~continuous monitoring for distribution drift.

%===========================================================================
\section{Future Work}\label{sec:future}
%===========================================================================

Key directions include: (1)~multi-source training combining Guardrailer Dataset~v1 with JailbreakBench, JailbreakHub, and other datasets; (2)~character-level normalization via leetspeak-aware tokenization and Unicode NFKD decomposition; (3)~semantic features using sentence transformer embeddings as additional inputs; (4)~cost-sensitive thresholding to reduce the 25.0\% false-positive rate; and (5)~domain adaptation using gradient reversal to learn domain-invariant features.

%===========================================================================
\section{Conclusion}\label{sec:conclusion}
%===========================================================================

This paper documents a systematic journey in prompt injection detection. The embedding method revealed that nearest-centroid scoring fails to achieve practical performance (AUC 0.547), suggesting that the evaluated general-purpose embedding models did not reliably expose security-relevant distinctions through the tested nearest-centroid scoring approach. Systematic investigation across embedding models shows the failure is primarily methodological: linear probes on the same embeddings achieve AUC 0.844--0.855, and reducing from 4 to 2 centroids substantially improves performance. We evaluated a lightweight hybrid guardrail (117 handcrafted features + TF-IDF + stacking ensemble) achieving 83.0\% in-distribution accuracy at 0.149\,ms/prompt. An ablation study revealed TF-IDF alone achieves 85.0\%, exceeding the full hybrid by 2.0 pp, indicating handcrafted features do not provide complementary value under the evaluated setting. Cross-dataset evaluation reveals a severe generalization gap (31.5 pp decline to 51.5\%). The most critical open challenge remains out-of-distribution generalization, requiring multi-source training data and evaluation protocols that test robustness under distribution shift.
